# Favicon concepts

Three original vector concepts prepared for review on September 24, 2026. Eric approved option A, Checked date. It is installed in the local DEV application.

- A, Checked date: a solid calendar page with a check. Recommended for recognition at 16px.
- B, Folded plan: a paper note with an outgoing arrow, emphasizing the input-to-calendar workflow.
- C, Calendar spark: an outlined calendar with a small spark, emphasizing AI assistance.

All options use the Paper + Pine colors. The comparison shows enlarged artwork, 16/32/48px previews and light/dark browser-tab contexts. Source SVGs are editable; comparison.png is a rendered review sheet. The application assets are in `src/calendar_helper_ai/static/icons/`: SVG, a 16/32/48px ICO, PNG sizes, and a 180px Apple touch icon. Template icon links and the `/favicon.ico` fallback serve the selected design. The comparison retains the alternatives as design history.
